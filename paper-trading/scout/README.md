# 데이터 스카우트 (모의 매매용)

DexScreener 공개 API(키 필요 없음)에서 정해 둔 종목의 가격·유동성·거래량 스냅샷을 일정 간격으로 CSV에 기록해. 주문은 넣지 않고 기록만 하는 봇이야. 이렇게 쌓인 기록은 나중에 청산 감시 봇이 "규칙이 제때 울렸는지" 확인하는 기준 데이터로 써.

## 실행

```bash
node scout.mjs                         # 60초 간격으로 계속 실행
node scout.mjs --interval 60 --ticks 10
node scout.mjs --out ./data --watchlist ./watchlist.json
```

필요한 건 Node 18 이상뿐이고 따로 설치할 패키지는 없어. 결과는 `data/YYYY-MM-DD.csv`에 날짜별로 쌓이고, 이 폴더는 git에 올라가지 않아.

## 종목 고르는 방식

종목은 `watchlist.json`에 **컨트랙트 주소**로 적어. 심볼로 검색하면 이름만 비슷한 가짜 토큰이 잡히거든. 실제로 "BONK"로 검색해서 유동성이 제일 큰 페어를 고르면 가짜 "Bonk Coin"이 나와. 가격은 진짜보다 약 7배 높고, 24시간 거래량은 $2.45밖에 안 돼.

주소마다 페어를 이렇게 하나 골라.

1. 기준 토큰(base token) 주소가 일치하는 페어만 남겨.
2. 그중 유동성이 `minLiquidityUsd` 이상인 것만 남겨.
3. 남은 것 중 24시간 거래 건수가 가장 많은 페어를 써. 신호 봇의 거래 활발·매수 우위 조건이 이 페어의 거래 건수를 보기 때문이야. 거래량(금액)으로 고르면 WIF는 하루 1,326건짜리 풀이 잡혀. 거래 건수로 고르면 7,816건짜리 풀이 잡혀.

종목별로 `minLiquidityUsd`를 따로 적으면 그 종목에는 그 기준이 적용돼. POPCAT은 $100만으로 올려 뒀어. 유동성 $59만짜리 USDC 풀에서 매도 한 건에 가격이 -34%로 찍혔다가 6분 뒤 돌아온 일이 있었거든. 전체 기준을 올리면 WIF가 거래가 적은 풀로 돌아가서 종목별로만 걸었어.

고른 페어는 6시간마다 다시 확인해.

## 플래그

| 플래그 | 조건 |
|---|---|
| `JUMP_x%` | 직전 틱보다 가격이 ±15% 이상 움직였을 때 |
| `LIQ_DROP_x%` | 직전 틱보다 유동성이 30% 이상 줄었을 때 (러그 의심) |
| `NO_PRICE` | 가격 값이 비어 있을 때 |

## 주의

- DexScreener 값은 20~40초 정도 간격으로 갱신돼. 그래서 간격을 60초보다 짧게 잡아도 같은 값이 반복해서 찍혀.
- 기록과 관찰만 하는 용도야. 매수 추천이 아니야.
