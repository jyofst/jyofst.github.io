# 모의 매매 봇 팀

밈코인 모의 매매를 6개 역할의 봇으로 나눠서 돌리는 실험이야. 진짜 돈이나 지갑, 거래소는 연결하지 않아. 목표는 "정해 둔 규칙대로 매매했다면 청산 규칙이 제때 울렸을까"를 기록으로 검증하는 거야.

## 흐름

```
DexScreener ─▶ ① 스카우트 ─▶ CSV ─▶ ② 신호 ─▶ ③ 리스크 ─▶ ④ 모의 집행 ─▶ ⑤ 청산 감시 ─▶ ⑥ 기록·정산
(공개 API)      시세 기록          진입 조건     포지션 크기    가상 체결       손절·익절 규칙     성과·규칙 준수 리포트
```

| # | 봇 | 하는 일 | 상태 |
|---|---|---|---|
| ① | [스카우트](scout/) | 지켜볼 종목의 가격·유동성·거래량을 1분마다 CSV로 기록 | 완료 |
| ② | [신호](signal/) | 기록을 읽고 진입 조건을 전부 통과하면 후보 신호를 남김 | 완료 |
| ③④ | [시뮬레이터](sim/) | 쌓인 기록을 처음부터 다시 훑으면서 신호가 나면 가상으로 사고팔아. 포지션 크기와 동시 보유 한도(리스크), 수수료·슬리피지를 반영한 체결(모의 집행)을 함께 처리해 | 완료 |
| ⑤ | 청산 감시 | 보유 포지션을 틱마다 손절·익절·시간 청산·유동성 급감 규칙과 대조 | 예정 |
| ⑥ | 기록·정산 | 손익과 규칙 준수 여부, 규칙이 늦게 울린 사례를 정리 | 예정 |

봇끼리는 파일로만 주고받아(CSV, JSONL). 그래서 하나씩 따로 돌리고 따로 고칠 수 있어.

## 데이터 수집 방식

| 방식 | 어떻게 | 실제 커버리지 |
|---|---|---|
| GitHub Actions (기본) | `.github/workflows/scout.yml`이 예약 실행될 때마다 50분씩 수집하고, 신호 체크와 시뮬레이션까지 돌린 뒤 `scout-data` 브랜치에 커밋해 | 일정은 15분마다로 걸어 뒀지만, 실제로는 3~5시간에 한 번꼴로 실행돼. 그래서 하루 몇 시간 정도만 모여 |
| 상시 수집 (선택) | 항상 켜 둔 PC나 VM에서 아래 두 명령을 띄워 둬 | 24시간 |

```bash
node paper-trading/scout/scout.mjs                 # 60초 간격으로 계속 수집
node paper-trading/signal/signal.mjs --watch 60    # 60초마다 신호 체크
```

Actions 작업을 몇 시간씩 계속 이어 붙여서 상시 서버처럼 쓰는 방식은 일부러 쓰지 않았어. GitHub 이용약관상 애매한 영역이라서야.

## 참고: 월드모니터

[koala73/worldmonitor](https://github.com/koala73/worldmonitor)는 세계 뉴스, 지정학, 시장 데이터를 한 화면에 모아 보는 오픈소스 대시보드야. 이 저장소에 포함돼 있지 않고, 필요할 때 따로 설치해서 써. 공포탐욕지수나 예측시장 같은 시장 분위기 데이터를 나중에 신호 봇의 보조 필터로 붙일 수 있어.

모든 출력은 관찰 기록이야. 매수·매도 추천이 아니야.
